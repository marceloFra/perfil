# Portafolio React

Proyecto web creado con React y Vite para usar como base de un portafolio personal.

## Comandos

```bash
npm install
npm run dev
npm run build
```

## Personalizacion

Edita `src/App.jsx` para cambiar:

- Nombre, rol, ubicacion y correo.
- Resumen profesional.
- Lista de proyectos.
- Habilidades.

Los estilos principales estan en `src/App.css` y los estilos globales en `src/index.css`.
